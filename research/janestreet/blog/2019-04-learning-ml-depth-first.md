# Learning ML Depth-First

- Source: <https://blog.janestreet.com/learning-ml-depth-first/>
- Published: 2019-04-17
- Kind: blog post

## Summary

- Introduces Depth First Learning, a program that builds self-paced curricula leading up to
  one specific ML paper (AlphaGo Zero, DeepStack, InfoGAN, TRPO).
- Jane Street funded four fellowships to write new curricula and run six-week open online
  classes; 113 people applied.
- Winning topics: normalizing flows, spherical CNNs, Stein variational gradient descent, and
  dynamical isometry for sigmoid networks.
- Ties to the firm's culture of deep technical education: talks, conferences and internal
  classes built around specific libraries.
