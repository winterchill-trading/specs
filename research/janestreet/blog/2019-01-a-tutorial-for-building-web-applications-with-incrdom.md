# A tutorial for building web applications with Incr_dom

- Source: <https://blog.janestreet.com/a-tutorial-for-building-web-applications-with-incrdom/>
- Published: 2019-01-15
- Kind: blog post

## Summary

- Jane Street web UIs are built on Incr_dom, an in-house framework partly modeled on
  React's virtual DOM.
- Incr_dom sits on top of Incremental, since re-rendering views from a shared changing
  model is naturally an incremental computation.
- Until this post, documentation was limited to a few blog posts, a talk and API docs.
- The post announces example-driven tutorials in the incr_dom repository that walk through
  sample apps, from basics to more advanced features.

## Relevance to us

- Weak relevance: we have no web UI. If we ever build a dashboard over the recorder or the
  market maker, Incr_dom (or its successor Bonsai) would be the in-ecosystem option.
- **Action:** none.
