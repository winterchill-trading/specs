# ICFP 2024

- Source: <https://blog.janestreet.com/icfp-2024-index/>
- Published: 2024-08-29
- Kind: blog post

## Summary

- Lists the papers and talks with Jane Street involvement at ICFP 2024 in Milan, many with
  outside collaborators: modal memory management, arrows as applicatives in a monad, a
  non-allocating option, labeled tuples, mixed blocks, interrupts for ML, pattern matching on
  mutable values, rethinking the value restriction, and a Flambda2 validator.
- The OCaml Language team's broader work spans type-system features, code generation,
  register allocation and inlining, with a focus on modes (local, unique) and a kind system
  for unboxed layouts.
- The firm plans to upstream its extensions the way Multicore OCaml was upstreamed after
  years on a fork, through papers and hands-on use.
- Because public library releases erase extension use, it publishes a "bleeding-edge" opam
  repository with its compiler and unerased libraries so outsiders can try the features as
  insiders use them.
- Bonsai's new API hands a local-mode witness to graph-building code, so escape analysis
  enforces the two-phase discipline (build the graph, then run it) that the old API left
  easy to break with nested computation types.
- Unboxed types come with kinds (`value`, `immediate`, `word`, `float64`, `bits64`, unboxed
  tuples); mixed blocks let one record hold both GC-scanned pointers and flat unboxed
  fields, as in a trade record with a symbol string next to an unboxed price and size.
- Kind and mode polymorphism is still limited, so the identity function needs one copy per
  kind and mode; `ppx_template` stamps out such copies from one definition as a stopgap
  close to the eventual syntax.
- Labeled tuples, an intern project, spread quickly internally; `or_null`, a zero-overhead
  option using a null pointer, uses kinds to forbid nesting.

## Relevance to us

- **Performance:** our prices and sizes are `int`-backed `Fixed_decimal.Make ()` types, but
  [fixed-decimal](../../../repos/fixed-decimal.md) exports `type t` abstractly with no
  immediacy annotation, so the compiler must assume every `Price.t` field may be a pointer
  (write barriers on mutation, generic comparison paths). **Action:** mark `type t` as
  `[@@immediate]` in the `Fixed_decimal.Make` output signature and add a test that checks
  `Obj.is_int (Obj.repr price)` to pin the representation.
- **Performance:** mixed blocks and `or_null` are the features that would make
  [market-data](../../../repos/market-data.md) records and
  [order-book](../../../repos/order-book.md) levels flatter, but only once allocation is shown
  to matter (see the locality note's measurement action).
- **OCaml practice:** the local-witness trick enforces API phase discipline at compile time
  and could guard "configure, then run" APIs. Context only; no current API of ours has that
  bug class.
