# What the interns have wrought, special jumbo 2026 edition

- Source: <https://blog.janestreet.com/wrought-2026/>
- Published: 2026-09-30
- Kind: blog post

## Summary

- Index post for the 2026 intern projects, this year including ML research, Linux
  engineering, IT, Strategy and Product, and trading desk operations, each with its own
  write-up.
- ML: a recompute-selection scheme for activation checkpointing that beat PyTorch's, an
  event-level autoregressive diffusion model of market data, and work on measuring and
  reducing memorization in LLMs used for prediction.
- Shorter ML mentions: a network answering per-order questions about the future of any
  order on the book, sequence models with tree-search rollouts, KV-cache distillation for
  faster prefill, and bf16 versus fp32 degradation in a Mamba model.
- Software: an index for tip recovery in Aria (30% less CPU), and `lib/spmd`, an
  ISPC-like single-program-multiple-data DSL in OxCaml targeting CPU SIMD that separates
  schedule from code in the style of Halide.
- Also mentioned: hash-consing compression of debug graphs in an internal data-fetching
  library, ILP/SAT solvers replacing a greedy scheduler that places market data
  applications on hosts, and a feature library split into helper processes that share
  double-buffered state through shared memory.
- Linux and IT: a kernel log reporter that survives disk and network failure, an OCaml
  FUSE server for the Depot object store, and an OCaml orchestrator with an F# agent for
  Windows config, cut over by diffing old and new decisions.

## Relevance to us
